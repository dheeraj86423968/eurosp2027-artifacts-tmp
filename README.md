# EuroS&P 2027 artifacts — anonymized review package

- `paper-artifact.zip` — the anonymized review artifact (reference scorer, alert rows, per-host results, baselines
  summaries, EDR conversion manifests; **no detection engine**). Trimmed to fit the single-file size limit: the raw
  per-node arrays (`*.npz`) and baseline score CSVs are omitted; a note inside the zip's README says what and why.

All datasets are public (from their creators / PIDSMaker). The detection engine is not released.
